# Installation

Isoatlas is published as a **React component** you can embed into your project.

To install using `npm`:

```bash
npm install isoatlas
```

or `yarn`:

```bash
yarn add isoatlas
```

### Running Isoatlas in development mode
To run Isoatlas on your local machine:

1. Clone the [Github repository](https://github.com/enixCode/isoatlas).
2. `npm ci`
3. `npm run start`.

### Developer documentation
Build and run the docs locally:

- `npm run docs:build`
- `npm run docs:start`
