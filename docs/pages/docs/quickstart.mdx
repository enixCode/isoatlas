# Quick Start

Isoatlas can be imported as an ES6 module:

```jsx
import Isoatlas from "isoatlas";
```

### Basic usage

```jsx showLineNumbers
import React from 'react';
import Isoatlas from 'isoatlas';

const App = () => {
  return (
    <Isoatlas />
  );
}

export default App;
```

**Note**: this will display a blank Isoatlas editor, without icons (which is not very useful!).  To initialise the editor with an iconset, see [Loading Isopacks](/docs/isopacks).

### Dimensions of Isoatlas

Isoatlas takes _100%_ of `width` and `height` of the containing block so make sure the container in which you render Isoatlas in has non-zero dimensions.

### Integration with NextJS

Isoatlas cannot be server-side rendered and has to be imported using `next/dyanmic`:

```jsx showLineNumbers filename="IsoatlasDynamic.jsx"
import dynamic from 'next/dynamic';

export const IsoatlasDynamic = dynamic(() => {
    return import('isoatlas');
  },
  {
    ssr: false
  }
);
```

```jsx showLineNumbers filename="App.jsx"
import { IsoatlasDynamic } from './IsoatlasDynamic';

const App = () => {
  return (
    <IsoatlasDynamic />
  );
}

export default App;
```
